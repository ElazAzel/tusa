## 2. Детальный разбор по зонам интерфейса

### 2.1. Главная страница (Landing & Waitlist)
- **Сильные стороны**:
  - Яркий нео-брутализм с сочными акцентами (лаймовый, розовый, ультрамарин).
  - Четкие баннеры «1 ссылка без скачивания», «32 режима», «QR-код для тусы».
  - Динамическая презентация мокапа приложения (`.event-app`).
- **Точки роста**:
  - Компактность Cookie-баннера на мобильных устройствах (< 390px) для исключения перекрытия CTA-кнопок.
  - Сохранение контрастности badges (стикеры `--lime` всегда с темным текстом `#000000`).

### 2.2. Навигация и Party Room (`PartyRoom.tsx`)
- **Сильные стороны**:
  - Адаптивная навигационная рельса (Rail) на desktop и удобный нижний Dock на mobile.
  - Закрепленная плашка события (Sticky Topbar) с быстрым доступом к коду комнаты и статусу сети.
  - Разделение видов: Stage (экран вечеринки) и Controller (пульт игрока).
- **Точки роста**:
  - Оптимизация вертикального пространства на экранах iPhone SE / Android compact (< 667px height).

### 2.3. Игровые экраны (Stage vs. Controller)
- **Stage**:
  - Крупные шрифты (`Unbounded`), таймеры с динамической цветовой индикацией (зеленый → желтый → красный).
  - Скрытые секретные состояния (карт/ролей) от экрана ведущего.
- **Controller**:
  - Большие кнопки выбора ответов и ввода текста.
  - Визуальные уведомления при получении KOINS или отправке ответа.

### 2.4. Доступность и i18n
- Все интерактивные элементы имеют четкие `:focus-visible` рамки (розовый/лаймовый контур).
- Поддержка переключателя языков RU / EN с мгновенной адаптацией всех 32 игровых текстовых ресурсов.

## 3. План UX/UI улучшений (Actionable Roadmap)

1. **Short-term (1–7 дней)**:
   - Проверить и укрепить правило `:active` состояния для всех мобильных кнопок.
   - Гарантировать `min-height: 44px` для иконочных кнопок в мобильных диалогах.
2. **Mid-term (8–30 дней)**:
   - Добавить встроенный переключатель темы оформления комнаты (Dark Club Mode / Daylight Party).
   - Расширить анимационные микро-отклики (звуковой + визуальный confetti при победе).
