## Core Insight

TUSA should not be positioned as a "platform with games" but as a **Social OS for real-life gatherings**. The key architectural correction: **everyone is a player on their own device** — no TV/stage split. All users see the full game on their phone or computer.

## Key Proposals

1. **Three-Pillar Experience**: Stage (shared view), Controller (personal device), Lobby (async between sessions)
2. **Social Capital over Points**: Collectible memories, room customization, social quests, gratitude economy
3. **Viral Growth**: One-link portal, spectator mode, async teasers
4. **Monetization**: Battle Pass, cosmetic economy, premium hosting, B2B, party sponsorship
5. **Content Engine**: Game Drops every 2 weeks, Creator Games, Licensed IPs
6. **Social Contracts**: Scheduled parties, ghost rooms (AI bots), spectator arc

## Architecture Correction

**Current**: Stage (host, game board) + Controller (players, input only)
**Target**: All players see full game on their own device. Host has admin controls.
