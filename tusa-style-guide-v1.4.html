Правила · Rules

  • Всегда подсвечиваем «сегодня» чёрной обводкой.
  • Выбранная дата — лаймовый фон + offset-тень.
  • Розовая точка = запланированная туса.

18 · v1.2 — Motion library

Motion library

Onboarding · confetti-win · screen transitions

Стандартные движения TUSA: как встречаем нового человека, как празднуем победы и как перекладываем экраны между собой.

Онбординг · Onboarding (3 шага)

🔗
STEP 01 / 03

Одна ссылка — вся туса

Создай ивент за 30 секунд и кинь ссылку в чат. Никто не скачивает приложение.

🎮
STEP 02 / 03

Играй прямо внутри

25 мини-игр, ставки между своими, живая галерея. Всё открывается в один тап.

📸
STEP 03 / 03

Сохраняй воспоминания

Фотки, победы и мемы остаются в тусе навсегда. Можно вернуться и переслушать смех.

Motion: onb-in · translateY(14px) + rotate(-.4deg) → 0/0 · 400ms · cubic-bezier(.2,.8,.2,1). Задержка между карточками — 80ms.

Confetti-win · победы

🏆

Ты выиграл в «Мафию»!

+120 XP · +1 стрик · +уважение всей тусы. Скрин уже в галерее.

Правила · Rules

  • Запускаем confetti только на реальных победах — не при обычных сабмитах.
  • Длительность одной частицы — 3.2s, всего частиц — 24. Не больше.
  • Цвета: lime, pink, blue, black.
  • Trophy пульсирует в бесконечном лупе с амплитудой 6%.
  • Уважаем prefers-reduced-motion — тогда только статичный кубок.
confetti.cssCopy
@keyframes confetti-fall {
  0%   { transform: translate3d(0,-20px,0) rotate(0); opacity: 0 }
  10%  { opacity: 1 }
  100% { transform: translate3d(var(--cx), 260px, 0) rotate(720deg); opacity: 0 }
}

Screen transitions · переходы

Лента тусы
→
Открытая туса
slide-forward translateX(24px) → 0 · opacity 0 → 1 320ms · cubic-bezier(.2,.8,.2,1) Основной переход «вперёд» — открытие тусы, деталей игры, чата.
slide-back translateX(-24px) → 0 · opacity 0 → 1 280ms · cubic-bezier(.2,.8,.2,1) Возврат «назад». Всегда чуть быстрее, чем slide-forward.
modal-up translateY(28px) → 0 · opacity 0 → 1 320ms · cubic-bezier(.2,.8,.2,1) Модалки, sheet-меню, action-panel снизу.
fade-swap opacity 0 → 1 · scale .98 → 1 200ms · ease-out Смена вкладок в одной секции (Игры / Галерея / Покупки).
pop-in scale .8 → 1 · opacity 0 → 1 240ms · cubic-bezier(.34,1.56,.64,1) Появление новых элементов в ленте (фото, сообщение).
reduced-motion opacity 0 → 1 · duration 1ms prefers-reduced-motion: reduce Fallback: всё движение выключается, остаётся только opacity.
