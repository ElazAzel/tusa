# TUSA.game — план доведения до production

## Уже сделано

- аутентифицированные профили, тусы, инвайты, ожидание, промокоды и базовая админка;
- выдача промонаград: бета-доступ, обложка, рамка, эффект сообщений, цвет имени, ачивка, XP и право создавать тусы;
- режим 18+ с безопасной семейной альтернативой;
- отдельная комната созданной тусы и безопасная ссылка входа;
- корректная offline-обработка и кнопка установки на телефон.

## Следующий серверный релиз

1. **Комнаты и realtime.** Добавить WebSocket/Realtime слой, события присутствия, чат, роли хоста/модератора, непрерывное состояние игры.
2. **Игры.** Перенести режимы из текущего локального демонстратора в party rooms. Для каждой игры использовать единый lifecycle: lobby → ready → round → reveal → leaderboard → rematch. Сначала Alias, UNO, Quiz и Mafia; затем остальные режимы из игрового руководства.
3. **Галерея.** Подключить объектное хранилище, права доступа на фото, загрузку, сжатие, live-ленту, теги и recap.
4. **Роли и модерация.** Ввести owner, co-host, moderator, partner-manager, analyst, support и назначение прав в админке.
5. **Партнёрская сеть.** Каталог заведений и предложений, кампании, нативные placements в конкретной тусе, лимиты показов, клики и конверсии.
6. **Аналитика.** События регистрации, создания тусы, входа, запуска игры, загрузки фото, использования кода, показа и клика рекламы. Админская сводка строится только по этим событиям.

## Ограничения, которые нельзя имитировать локально

- production-ключи Google/Apple OAuth: Apple требует аккаунт Apple Developer, Google/Apple включаются в production-инстансе Clerk;
- push-уведомления: требуется VAPID/сервер отправки и явное разрешение браузера;
- полноценная многопользовательская игра и галерея: нужны серверные realtime-соединения и файловое хранилище.
