# TUSA.game

Твоя туса. Твои правила: одна ссылка для гостей, игр, покупок, фотографий, чата и KOINS.

## Что готово

- адаптивный лендинг в визуальной системе TUSA.game;
- официальные длинный и компактный логотипы;
- local-first платформа встречи на `/demo` с несколькими ивентами;
- Event Hub: создание, редактирование, дублирование, удаление, RSVP, роли, заметки, QR и Blast;
- 8 рабочих игр: Alias, Mafia Lite, Truth or Dare, Never Have I Ever, Beer Pong, Quiz Battle, Random Pair и Uno Tracker;
- покупки с защитой от дублей, назначением покупателя, ценами и расчётом сплита;
- чат с тредами, реакциями, закрепами, удалением и голосовыми сообщениями;
- KOINS с пулами, odds, ставками, расчётом исхода и журналом транзакций;
- галерея с bulk upload, сжатием, тегами, обложкой, FlashBack и recap;
- профиль с VibeScore, streak, лигами, 60 типами бейджей, рамкой и экспортом данных;
- приглашение через Web Share, копирование ссылки и синхронизация между вкладками;
- локальное сохранение состояния платформы в браузере;
- PWA-манифест, service worker и offline-экран;
- SEO/Open Graph metadata, 404 и мобильная навигация.

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Проверки перед публикацией:

```bash
npm run lint
npm test
npm run build
```

## Архитектура

- Next.js 16 App Router
- React 19 + TypeScript
- CSS-дизайн-система без runtime UI-зависимостей
- localStorage + `storage` events для local-first состояния и синхронизации вкладок
- Neon Postgres для общей waitlist: лимит 765, стартовая очередь 254 и реальные заявки с сайта;
- защищённая админка `/admin`: поиск, фильтры, статусы, заметки, удаление, CSV-экспорт и настройка лимита;
- Vercel для production hosting

## Аккаунты и промодоступ

- `/sign-in` и `/sign-up` — авторизация через Clerk; включённые в Clerk способы (Google и Apple) показываются в готовой форме входа;
- `/app` — серверный профиль пользователя, созданные и добавленные тусы;
- `/app/new` — создание тусы через промокод. До запуска платежей предзагружены одноразовые коды `ELAZ`, `JEDAI`, `TUSA02`;
- `/join/[inviteCode]` — защищённое присоединение к тусе и ссылка, которой можно делиться;
- `/admin/promos` — защищённая админ-консоль промокодов: создание, включение/пауза, удаление неиспользованных кодов и метрики пользователей, тус и активаций.

## Граница текущей версии

Демо `/demo` остаётся local-first и синхронизируется между вкладками одного браузера. Новый кабинет, профили, приглашения и промокоды хранятся в Neon и работают между устройствами после входа. Оплата намеренно не подключена: создание тусы пока открывается промокодом. Waitlist хранится отдельно в Neon и доступна команде через защищённый `/admin`; пароль и секрет сессии задаются в Vercel environment variables.
